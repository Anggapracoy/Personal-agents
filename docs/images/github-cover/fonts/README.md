# Cover typography studies

These unmodified variable fonts were downloaded from Google Fonts on October 8, 2026. Each retains its accompanying SIL Open Font License 1.1 notice.

- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope — `Manrope-OFL.txt`
- Inter Tight: https://github.com/google/fonts/tree/main/ofl/intertight — `InterTight-OFL.txt`
- Plus Jakarta Sans: https://github.com/google/fonts/tree/main/ofl/plusjakartasans — `PlusJakartaSans-OFL.txt`

The cover variants use weight 700. Only the headline typography changes; all screenshots and device frames remain directly composited from the existing images.
