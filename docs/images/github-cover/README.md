# GitHub cover

The current cover, `dash-cover.png` (also saved as `dash-cover-real.png`), is a direct 3840 × 2160 composite of the actual simulator PNGs:

- `feed.png`
- `proactive-chat.png`
- `montreal-keyboard.png`

No image generation is used for this version. `compose-real.py` only scales, positions and rotates the original captures, adds the existing landing-page phone frame and a headline, and applies the requested 90% opacity to the outer two screens. The center screenshot is fully opaque. The captured screens use preview/sample data.

The older `v2`/`v3` files and prompt records are superseded generated drafts.

The current framed version is also saved as `dash-cover-framed.png`. Its frame is the existing `public/landing/iphone-16-pro-black-hires.png` asset; the upstream MIT notice remains in `public/landing/iphone-frame-LICENSE.txt`.

The approved headline font is Manrope Bold (weight 700), with slightly tightened letter spacing. `cover-manrope.png` matches the current canonical cover. Its OFL notice is included in `fonts/Manrope-OFL.txt`.
